My space trails

Things I launched into the void that somehow still work.

Map bits
  • leaflet-city-mapper: a small 3D rendering engine for leaflet
  • leaflet-control-layers-inline: inline layers control
  • leaflet-elevation: display elevation profiles using d3js
  • leaflet-edit-osm: unobtrusive edit in osm control
  • leaflet-gesture-handling: prevent default map scroll/touch behaviours
  • leaflet-google: easy integration with the Google Maps API
  • leaflet-npm: skeleton repo to start bundling Leaflet Maps
  • leaflet-kmz: KML/KMZ file loader
  • leaflet-pegman: easy integration with the Google StreetView Service API
  • leaflet-pointable: interact with semi-transparent tiled overlays
  • leaflet-rotate: add rotation functionality to map tiles
  • leaflet-trails: easy integration with Lonvia's Waymarked Trails Site
  • leaflet-transparency: opacity slider control
  • leaflet-ui: presets for common user interface customizations
  • tile-proxy-php: caching-Proxy for WMTS Servers
  • google-geolocate: geolocation control
  • google-transparency: opacity slider control
Web bits
  • cockpit-blog: skeleton repo to start building Cockpit Sites
  • cockpit-native-lazy-loading: native lazy loading addon for Cockpit CMS
  • cockpit-extended-forms: improved core Forms module for Cockpit CMS
  • cockpit-honeypot: honeypot addon for Cockpit CMS
  • wordpress-git: skeleton repo to start building WordPress Sites
  • iubenda-for-wp: WordPress plugin to allow non-JavaScript use of Iubenda's policy API
  • wp-devops: helper plugin for every WP Developer
