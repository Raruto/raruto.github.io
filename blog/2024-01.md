# Workflow API Changes and Community Files

*Devlog: 2024-01*

In January I contributed to g3w-suite projects. I opened [g3w-client](https://github.com/g3w-suite/g3w-client) pull requests to delete [src/utils/ol/index.js](https://github.com/g3w-suite/g3w-client/pull/542) and [src/utils/geo/index.js](https://github.com/g3w-suite/g3w-client/pull/543), to refactor the [response parsers](https://github.com/g3w-suite/g3w-client/pull/541), and to remove the [g3wsdk.core.workflow API](https://github.com/g3w-suite/g3w-client/pull/545). The matching [editing plugin pull request](https://github.com/g3w-suite/g3w-client-plugin-editing/pull/87) brings those files into the plugin. I also opened issues about [deprecating internal components](https://github.com/g3w-suite/g3w-client/issues/547) and getting rid of the [LayoutManager plugin](https://github.com/g3w-suite/g3w-client/issues/546).

Elsewhere, I opened a [refactor of the API and Workflows classes](https://github.com/g3w-suite/g3w-client-plugin-editing/pull/85) in the editing plugin, and a [pull request for g3w-admin](https://github.com/g3w-suite/g3w-admin/pull/706) adding edit and layers URLs to the initial client API response. I also opened a [pull request replacing the OpenRouteServicePanel class](https://github.com/g3w-suite/g3w-client-plugin-openrouteservice/pull/1) with a g3wsdk.gui.Panel instance.

On the community side, I worked on the organization's [.github repository](https://github.com/g3w-suite/.github), opening pull requests for [default community files](https://github.com/g3w-suite/.github/pull/2) and a [backport workflow](https://github.com/g3w-suite/.github/pull/3), then proposed the [same workflow for g3w-client](https://github.com/g3w-suite/g3w-client/pull/557). I also reviewed pull requests in g3w-client and the editing plugin, including the [geocoding fix](https://github.com/g3w-suite/g3w-client/pull/555) and the [missing cloneFeature method](https://github.com/g3w-suite/g3w-client-plugin-editing/pull/89). Commits also landed in g3w-admin, g3w-admin-ps-timeseries, the demo projects and the community repository.
