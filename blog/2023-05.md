# Requirements Splitting, Nginx Env Vars and Elevation Gradients

*Devlog: 2023-05*

May was a month spread across the G3W-SUITE ecosystem for me. In [g3w-admin](https://github.com/g3w-suite/g3w-admin), I opened pull requests to [split and refactor requirements.txt](https://github.com/g3w-suite/g3w-admin/pull/546) and to [refactor the qdjango.apps logger](https://github.com/g3w-suite/g3w-admin/pull/547). I also opened an issue about [showing alternate EPSG names](https://github.com/g3w-suite/g3w-admin/issues/552) for the coordinate reference system. Around the same time I authored commits in g3w-admin-portal, g3w-client and g3w-admin-sentry-monitor, where I opened pull requests to [move settings overrides into apps.py](https://github.com/g3w-suite/g3w-admin-sentry-monitor/pull/3) and to [upgrade setuptools](https://github.com/g3w-suite/g3w-admin-sentry-monitor/pull/4).

On the Docker side, I opened a pull request to [support env variables in nginx.conf.template](https://github.com/g3w-suite/g3w-suite-docker/pull/99) and an issue proposing a [bash alias for manage.py](https://github.com/g3w-suite/g3w-suite-docker/issues/95). I also reviewed pull requests in g3w-client, including the one [replacing the vendors folder with npm packages](https://github.com/g3w-suite/g3w-client/pull/413), and reviewed a [custom nginx 502 page](https://github.com/g3w-suite/g3w-suite-docker/pull/97).

Outside G3W, I authored commits in [leaflet-elevation](https://github.com/Raruto/leaflet-elevation) and opened pull requests there to [add a lineargradient handler](https://github.com/Raruto/leaflet-elevation/pull/257) and to [replace structuredClone with a custom cloneDeep](https://github.com/Raruto/leaflet-elevation/pull/256). I also opened a [pull request in togeojson](https://github.com/placemark/togeojson/pull/110) to fix tests.
