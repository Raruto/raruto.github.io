# Projection, WMS and Build Fixes Under Review

*Devlog: 2025-03*

In March I authored commits and reviewed pull requests in [g3w-client](https://github.com/g3w-suite/g3w-client). The reviews covered a range of fixes and additions: [zooming to a feature when the projection has inverted axes](https://github.com/g3w-suite/g3w-client/pull/767), [a missing FORMAT parameter in WMS GetMap requests](https://github.com/g3w-suite/g3w-client/pull/764), and [sending the ordering parameter only after a user clicks a table column](https://github.com/g3w-suite/g3w-client/pull/762). I also looked at [a new g3w data provider with a refactored area query control](https://github.com/g3w-suite/g3w-client/pull/757) and [a new CSS variable, bgcolor](https://github.com/g3w-suite/g3w-client/pull/760).

I reviewed two pull requests about [preventing static assets from g3w-admin plugins being copied during npm run build](https://github.com/g3w-suite/g3w-client/pull/759), as well as one on [showing a warning when the user themes API returns a server error](https://github.com/g3w-suite/g3w-client/pull/754). Over in [g3w-client-plugin-editing](https://github.com/g3w-suite/g3w-client-plugin-editing), I authored a commit and [reviewed a change improving the look of very long layer names in the editing toolbox](https://github.com/g3w-suite/g3w-client-plugin-editing/pull/154).

On the deployment side, I opened [a pull request in g3w-suite-docker](https://github.com/g3w-suite/g3w-suite-docker/pull/137) to fix an invalid ID that appeared when running make db-reset ENV=dev with the default demo, and I authored a commit in that repository too.
