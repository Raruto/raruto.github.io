# Devlog: 2018-06

On June 27, 2018, I opened a feature request on the [waymarked-trails-site](https://github.com/waymarkedtrails/waymarked-trails-site) repository. The idea: a URL parameter for choosing the basemap type, so a map link could specify which base layer it should show.

The [feature request](https://github.com/waymarkedtrails/waymarked-trails-site/issues/299) describes the proposal.
