I opened a pull request to [add a Sentry monitoring plugin integration](https://github.com/g3w-suite/g3w-admin/pull/539), another to [prevent i18n from being applied to static asset URLs in debug mode](https://github.com/g3w-suite/g3w-admin/pull/528), and an issue asking whether the [SECRET\_KEY was unsafe](https://github.com/g3w-suite/g3w-admin/issues/523). I also filed a few issues about the server messages UI, including [date formatting changing after saving](https://github.com/g3w-suite/g3w-admin/issues/535) and [missing breadcrumbs on translated pages](https://github.com/g3w-suite/g3w-admin/issues/538).

I reviewed several pull requests along the way too, such as [displaying server messages on first page load](https://github.com/g3w-suite/g3w-client/pull/401) and [generating a unique SECRET\_KEY\_FILE on deploy](https://github.com/g3w-suite/g3w-admin/pull/531). I also reviewed [moving the authjwt settings overrides into apps.py](https://github.com/g3w-suite/g3w-admin-authjwt/pull/1).

On the Leaflet side, I authored commits in [leaflet-elevation](https://github.com/Raruto/leaflet-elevation) and [leaflet-rotate](https://github.com/Raruto/leaflet-rotate). I opened pull requests there for a [leaflet-edgescale integration](https://github.com/Raruto/leaflet-elevation/pull/246), a [labels handler](https://github.com/Raruto/leaflet-elevation/pull/252), a [runner handler](https://github.com/Raruto/leaflet-elevation/pull/254), and a [fix for undefined track\_info data in the eledata\_loaded event](https://github.com/Raruto/leaflet-elevation/pull/253).
