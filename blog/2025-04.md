# Devlog: 2025-04

In April I authored commits in [g3w-client](https://github.com/g3w-suite/g3w-client) and opened two pull requests: one to [remove src/index.html](https://github.com/g3w-suite/g3w-client/pull/779) and another to [allow G3WObject setters to be specified as an array of strings](https://github.com/g3w-suite/g3w-client/pull/782).

I also reviewed pull requests. I looked at pull requests on [pagination parameters for child layers](https://github.com/g3w-suite/g3w-client/pull/781), [filter/selection within paginated tables](https://github.com/g3w-suite/g3w-client/pull/787), and a [new QGIS arcgisfeatureserver layer type](https://github.com/g3w-suite/g3w-client/pull/789). I also reviewed [searching relation table columns](https://github.com/g3w-suite/g3w-client/pull/771) and a [missing FORMAT parameter in server requests](https://github.com/g3w-suite/g3w-client/pull/764). Beyond the client, I reviewed a change in the [qplotly plugin](https://github.com/g3w-suite/g3w-client-plugin-qplotly/pull/10) and opened an issue in g3w-admin about a [billboards module](https://github.com/g3w-suite/g3w-admin/issues/1083).
