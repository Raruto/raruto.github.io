# Street View, Static Plugins and Bug-Fix Reviews

*Devlog: 2025-02*

In February I authored commits and reviewed pull requests in [g3w-client](https://github.com/g3w-suite/g3w-client). I looked over a run of bug-fix pull requests, including one that [clears a layer's filter when the TOC selection icon is clicked](https://github.com/g3w-suite/g3w-client/pull/747), another on [downloading layer features from search with pagination](https://github.com/g3w-suite/g3w-client/pull/743), and one on [preventing invalid proj4 definitions](https://github.com/g3w-suite/g3w-client/pull/737). I also reviewed several iframe-related fixes, such as the [editing panel not opening for more than one layer](https://github.com/g3w-suite/g3w-client/pull/736).

On the authoring side, I opened two pull requests about [Street view not showing on subsequent map clicks](https://github.com/g3w-suite/g3w-client/pull/716) and one making [normal the default font weight](https://github.com/g3w-suite/g3w-client/pull/711). I also opened a pull request to [convert g3w-admin-processing to a static plugin.js](https://github.com/g3w-suite/g3w-admin-processing/pull/16), and filed an [issue about autofocus on the password field](https://github.com/g3w-suite/g3w-admin/issues/1049) on the profile page.

I also made commits in [g3w-client-plugin-editing](https://github.com/g3w-suite/g3w-client-plugin-editing), where I reviewed a [pull request on filtering editable relations](https://github.com/g3w-suite/g3w-client-plugin-editing/pull/148), and in my own [leaflet-pegman](https://github.com/Raruto/leaflet-pegman) and [leaflet-elevation](https://github.com/Raruto/leaflet-elevation) projects.
