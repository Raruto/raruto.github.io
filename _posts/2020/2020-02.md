# Dependency Installer Pull Requests and Leaflet Plugin Commits

*Devlog: 2020-02*

In February I opened pull requests on [wp-dependency-installer](https://github.com/afragen/wp-dependency-installer), including [Required label](https://github.com/afragen/wp-dependency-installer/pull/39), [Register config](https://github.com/afragen/wp-dependency-installer/pull/44), [Cleaner install conditions](https://github.com/afragen/wp-dependency-installer/pull/48) and [Chainable init](https://github.com/afragen/wp-dependency-installer/pull/59). I also opened issues, such as [Basic Authentication headers?](https://github.com/afragen/wp-dependency-installer/issues/41) and [a "get\_config" abstraction](https://github.com/afragen/wp-dependency-installer/issues/57), and reviewed other pull requests, like [Customization filters](https://github.com/afragen/wp-dependency-installer/pull/55) and [Cleaner admin notices](https://github.com/afragen/wp-dependency-installer/pull/60). Commits landed there throughout the month.

I also authored commits across [leaflet-elevation](https://github.com/Raruto/leaflet-elevation), [leaflet-ui](https://github.com/Raruto/leaflet-ui), [leaflet-trails](https://github.com/Raruto/leaflet-trails) and [raruto.github.io](https://github.com/Raruto/raruto.github.io), plus several smaller plugins like leaflet-kmz and leaflet-pegman.
