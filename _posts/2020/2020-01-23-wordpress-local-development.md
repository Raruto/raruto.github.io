# Keeping Local Checkouts Local

*Contributions: 2020-01*

Looking back to January, WordPress.org lists me among the contributors to [Local Development](https://wordpress.org/plugins/local-development/), a plugin by Andy Fragen for marking plugins and themes as being under local development.

The plugin's 2.5.0 changelog, dated January 23, 2020, credits me for automatically adding version-control checkouts. In the [pull request](https://github.com/afragen/local-development/pull/5), I also addressed an edge case where a parent directory was under version control. The change was merged on January 19.

The plugin's current description says it marks development plugins and themes in the admin and prevents updates for selected items. A handy bridge between the files I'm working on and the WordPress admin screen.
