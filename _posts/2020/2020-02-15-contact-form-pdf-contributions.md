# PDFs, Forms, and a Couple of WordPress Errors

*Contributions: 2020-02*

Looking back to February, I filed two reports on [Send PDF for Contact Form 7](https://github.com/restezconnectes/send-pdf-for-contact-form-7), a plugin for generating PDFs from form submissions.

One described an [`.htaccess` directive causing server errors](https://github.com/restezconnectes/send-pdf-for-contact-form-7/issues/5) on shared hosting. The other reported a [`$ is not a function` error](https://github.com/restezconnectes/send-pdf-for-contact-form-7/issues/6) when deleting a PDF from the admin page. The reports document what I encountered; they don't establish that either problem was fixed.

I also sent a [small pull request](https://github.com/restezconnectes/send-pdf-for-contact-form-7/pull/7) adding a GitHub Plugin URI header for use with GitHub Updater. It was merged on February 15, bringing two bits of my WordPress work together.
