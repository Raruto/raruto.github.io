# Contributions to Local Development and Dependency Installer

*Devlog: 2020-01*

In January I contributed to [afragen/local-development](https://github.com/afragen/local-development): I opened issues about [automatically detecting plugins under development](https://github.com/afragen/local-development/issues/4) and [broken images in the readme](https://github.com/afragen/local-development/issues/3), then sent pull requests for [vcs detection](https://github.com/afragen/local-development/pull/5), [localhost styling](https://github.com/afragen/local-development/pull/6), [custom plugin headers with icon links](https://github.com/afragen/local-development/pull/7), and [keeping the vcs icon in the same position](https://github.com/afragen/local-development/pull/8). I also authored several commits there, and asked in [an issue](https://github.com/afragen/local-development/issues/11) about version 2.5.0 on wp.org.

Later in the month I moved over to [afragen/wp-dependency-installer](https://github.com/afragen/wp-dependency-installer), where I asked [how to contribute to develop](https://github.com/afragen/wp-dependency-installer/issues/34) and opened pull requests to [increase the "Plugin dependency" label visibility](https://github.com/afragen/wp-dependency-installer/pull/35), add a [dismiss label](https://github.com/afragen/wp-dependency-installer/pull/36), and introduce a [mandatory notice](https://github.com/afragen/wp-dependency-installer/pull/37), along with a few commits.

Elsewhere, I filed ideas on [git-updater](https://github.com/afragen/git-updater), such as an [REST API access log](https://github.com/afragen/git-updater/issues/837) and [tips to force check for updates](https://github.com/afragen/git-updater/issues/840), plus a [remote REST API endpoints](https://github.com/afragen/git-remote-updater/issues/3) issue on git-remote-updater. I also opened a [Version 1.0.0 pull request](https://github.com/szepeviktor/github-link/pull/10) on github-link and authored commits in [Raruto/wp-devops](https://github.com/Raruto/wp-devops).
