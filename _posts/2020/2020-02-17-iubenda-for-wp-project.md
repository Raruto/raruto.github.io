# A Shortcode for an Iubenda Policy

*Projects: 2020-02*

Looking back to February 2020, I forked [iubenda-for-wp](https://github.com/Raruto/iubenda-for-wp), a WordPress plugin originally maintained by [Ian James](https://github.com/injms/iubenda-for-wp). Its README describes retrieving a policy through Iubenda's API and caching it for display on a site.

I proposed [shortcode support and WordPress coding-style changes](https://github.com/injms/iubenda-for-wp/pull/1) upstream. The pull request was not merged. The project's documentation also describes a paid-service requirement for the non-JavaScript API, so check Iubenda's current terms before relying on this historical integration.
