# Cockpit Contributions: Translations, Paths, and Ideas

*Devlog: 2020-12*

In December I contributed to Cockpit-related projects. Early on, I opened a pull request on CpMultiplane titled [Prevent "C:\\\\" expansion](https://github.com/raffaelj/CpMultiplane/pull/30), alongside a couple of commits to the [same repository](https://github.com/raffaelj/CpMultiplane).

A few days later I turned to translations, authoring two commits in [agentejo/cockpit-i18n](https://github.com/agentejo/cockpit-i18n) and opening the pull request [Update / missing translations](https://github.com/agentejo/cockpit-i18n/pull/35).

Toward the end of the month I went back to CpMultiplane and opened two issues to track ideas: one about a [Routes file](https://github.com/raffaelj/CpMultiplane/issues/31) and another about [PHPDoc blocks](https://github.com/raffaelj/CpMultiplane/issues/32).

## Translations and Windows Paths in CpMultiplane

*Contributions: 2020-12*

Looking back to late 2020, I was exploring [CpMultiplane](https://github.com/raffaelj/CpMultiplane), a PHP frontend for Cockpit CMS. One contribution was an [Italian translation](https://github.com/raffaelj/CpMultiplane-i18n/pull/1), merged in November.

The next contributions had a distinctly Windows flavour. In the related library skeleton, I replaced a `cp` command in a Composer script with PHP's `copy()` in a [cross-platform pull request](https://github.com/raffaelj/cpmp-lib-skeleton/pull/2). Then I investigated a [path expansion problem](https://github.com/raffaelj/CpMultiplane/pull/30) when loading translations on Windows. Both changes were merged.
