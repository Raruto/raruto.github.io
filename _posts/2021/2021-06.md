# Gesture Handling and Elevation Plugin Commits

*Devlog: 2021-06*

In June I contributed to [leaflet-gesture-handling](https://github.com/Raruto/leaflet-gesture-handling) and [leaflet-elevation](https://github.com/Raruto/leaflet-elevation). The first helps an embedded map coexist with page scrolling; the second displays a track profile beside the map.

The gesture-handling history includes [removing old browser-specific CSS rules](https://github.com/Raruto/leaflet-gesture-handling/commit/668df0f866b5f2f13470739186ab613196badc4e) and merging a contributor's pull request. The current illustration below shows the control's prompt, while the [project article]({{ '/blog/2019-06-20-leaflet-gesture-handling-project.html' | relative_url }}) credits its original inspiration.
