# A Honeypot for Cockpit Forms

*Projects: 2021-01*

My [Honeypot](https://github.com/Raruto/cockpit-honeypot) repository and its [Packagist package](https://packagist.org/packages/raruto/cockpit-honeypot) date back to January 29. The add-on offers a honeypot option for Cockpit CMS forms.

The README describes adding and validating a field, then excluding invalid submissions from saved entries. It's one technique for reducing unwanted submissions, not a guarantee against spam. The add-on documents compatibility with Cockpit 0.11.2; check the version before using it with a newer installation.
