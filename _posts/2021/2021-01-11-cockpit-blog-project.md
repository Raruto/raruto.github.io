# Building a Blog Around Cockpit

*Projects: 2021-01*

My [cockpit-blog](https://github.com/Raruto/cockpit-blog) repository dates back to January. It's a small blog implementation with a router, initially based on a [Cockpit tutorial](https://github.com/Raruto/cockpit-legacy-docs/blob/master/tutorials/simple_blog.md).

The README maps out the pieces: PHP views for the theme, routes in the root entry point, assets, data and places for Cockpit add-ons. It makes a useful snapshot of how I put a site around the CMS; check its dependencies and compatibility before treating the historical setup as a current template.
