# A Map That Doesn't Have to Point North

*Projects: 2021-02*

North doesn't always need to be at the top. My [leaflet-rotate](https://github.com/Raruto/leaflet-rotate) repository, created in February, adds rotation to Leaflet maps.

The project was initially based on [Iván Sánchez Ortega's work](https://github.com/Leaflet/Leaflet/tree/rotate). The current README documents bearing, pitch and interaction options, while the [demo](https://raruto.github.io/leaflet-rotate/examples/leaflet-rotate.html) puts the controls on a map.

Bearing changes the map's orientation; pitch changes the viewing angle. The controls and gestures documented today offer different ways to explore those two adjustments.

# A Starting Point for Cockpit Experiments

*Contributions: 2021-02*

Looking back to February 15, I published two small Cockpit CMS packages on Packagist. [Sample Addon](https://packagist.org/packages/raruto/cockpit-sample-addon) adds a sample `/api/test` endpoint; [Sample Data](https://packagist.org/packages/raruto/cockpit-sample-data) automatically imports sample data during a Cockpit installation.

Both package pages link them to [cockpit-blog](https://github.com/Raruto/cockpit-blog) and document Composer installation. Their READMEs list compatibility with Cockpit 0.11.2, so these are best read as examples from that version rather than assumed to work with every current release.
