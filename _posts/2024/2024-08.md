# Atlas Print Autocompletion and Client Reviews

*Devlog: 2024-08*

In August I authored commits in [g3w-client](https://github.com/g3w-suite/g3w-client), [g3w-admin](https://github.com/g3w-suite/g3w-admin), and [g3w-client-plugin-editing](https://github.com/g3w-suite/g3w-client-plugin-editing).

On the pull request side, I opened a fix for [missing form autocompletion when the default print template is "Atlas"](https://github.com/g3w-suite/g3w-client/pull/652). I also reviewed a few others in the client: [grouping the query-by controls into a single map control](https://github.com/g3w-suite/g3w-client/pull/647), [updated French translations](https://github.com/g3w-suite/g3w-client/pull/654), and a [backport with some minor UX improvements](https://github.com/g3w-suite/g3w-client/pull/649).

The Atlas pull request includes a useful before-and-after: the form's name field gains its autocomplete input when Atlas is the default template. The fix was merged on August 7.
