# Absolute URLs, Print Formats and Chrome Cookies

*Devlog: 2024-05*

In May I contributed to the G3W-SUITE ecosystem. I committed to [g3w-admin](https://github.com/g3w-suite/g3w-admin) and [g3w-client](https://github.com/g3w-suite/g3w-client) throughout the month, and also added a commit to [g3w-client-plugin-editing](https://github.com/g3w-suite/g3w-client-plugin-editing). On the admin side, I opened a pull request to [ensure an absolute URL for initConfig.baseurl](https://github.com/g3w-suite/g3w-admin/pull/836), and I filed an issue about a [404 for map URL aliases](https://github.com/g3w-suite/g3w-admin/issues/843). The month ended with a pull request on [g3w-admin-portal](https://github.com/g3w-suite/g3w-admin-portal/pull/10) to fix the authentication flow for Chrome above 115 by removing Partitioned cookies.

I also reviewed a fair number of pull requests. In the client, they covered [custom DPI in print layouts](https://github.com/g3w-suite/g3w-client/pull/619), [GeoPDF, SVG and JPG print formats](https://github.com/g3w-suite/g3w-client/pull/623), [sorting print scales](https://github.com/g3w-suite/g3w-client/pull/627), and [hiding layers in the Table of Contents](https://github.com/g3w-suite/g3w-client/pull/625). On the admin side, I reviewed a [map alias URL fix](https://github.com/g3w-suite/g3w-admin/pull/844) and a [pull request showing system data information](https://github.com/g3w-suite/g3w-admin/pull/864).

I made a couple of commits to [Raruto/leaflet-rotate](https://github.com/Raruto/leaflet-rotate) as well, and reviewed a [new test for setting bearing and view](https://github.com/Raruto/leaflet-rotate/pull/53) there.
