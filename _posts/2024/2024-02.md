# Client Cleanup, Catalog Legends and Mobile Compass Permissions

*Devlog: 2024-02*

In February I contributed to the G3W-SUITE client. I opened a run of small cleanup pull requests that delete unused modules, like [componentsfactory.js](https://github.com/g3w-suite/g3w-client/pull/570) and [applicationservice.js](https://github.com/g3w-suite/g3w-client/pull/572), and I also opened a [refactor of the G3WObject, Panel and Component classes](https://github.com/g3w-suite/g3w-client/pull/574). Alongside that, I opened a [shortcut link to the docs in the navbar](https://github.com/g3w-suite/g3w-client/pull/576) and a [change to drop the branch name suffix on stable releases](https://github.com/g3w-suite/g3w-client/pull/578).

I also dealt with a couple of bugs. I opened an [issue about the grayed-out catalog legend items](https://github.com/g3w-suite/g3w-client/issues/580) along with a [pull request to fix that regression](https://github.com/g3w-suite/g3w-client/pull/581). I opened another [issue about an external WMS layer throwing an error](https://github.com/g3w-suite/g3w-client/issues/582). On the admin side, I opened a [pull request to make custom userscripts easier to inject](https://github.com/g3w-suite/g3w-admin/pull/746).

Beyond my own changes, I reviewed several pull requests, including the [print layout with no maps](https://github.com/g3w-suite/g3w-client/pull/587) one and a [single gulpfile for the client plugins](https://github.com/g3w-suite/g3w-client/pull/485). In [leaflet-rotate](https://github.com/Raruto/leaflet-rotate), I opened a [pull request to request permission for the mobile compass](https://github.com/Raruto/leaflet-rotate/pull/49) and reviewed one about [preventing rotation when zooming](https://github.com/Raruto/leaflet-rotate/pull/48).
