# Search Name Fallback and Multilayer Search Reviews

*Devlog: 2026-06*

In June I authored commits in [g3w-client](https://github.com/g3w-suite/g3w-client) and [g3w-admin](https://github.com/g3w-suite/g3w-admin). On the admin side, I opened a pull request adding a [fallback for the search name](https://github.com/g3w-suite/g3w-admin/pull/1422).

Reviewing was a big part of the month too. In the client, I reviewed pull requests on [forcing the layer title in the sidebar legend](https://github.com/g3w-suite/g3w-client/pull/958), [zooming to features on multilayer search](https://github.com/g3w-suite/g3w-client/pull/957), [avoiding a preview image when only a file name field exists](https://github.com/g3w-suite/g3w-client/pull/955), and [support for external ArcGIS MapServer sources](https://github.com/g3w-suite/g3w-client/pull/937). I also looked at [a fix for cyclic values in permalink creation](https://github.com/g3w-suite/g3w-client/pull/942) and [a Datetimepicker dialog that wouldn't open](https://github.com/g3w-suite/g3w-client/pull/940).

Over in [g3w-suite-docker](https://github.com/g3w-suite/g3w-suite-docker), I reviewed a change to [suppress xvfb warnings](https://github.com/g3w-suite/g3w-suite-docker/pull/165) and another on [sharing common docker-compose configurations](https://github.com/g3w-suite/g3w-suite-docker/pull/79) between PROD and DEV environments.
