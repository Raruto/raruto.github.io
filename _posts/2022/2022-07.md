# Refactoring g3w-client Structure and Plugin Constructors

*Devlog: 2022-07*

In July I contributed to the G3W-SUITE ecosystem, including [g3w-client](https://github.com/g3w-suite/g3w-client). I opened a run of refactoring pull requests there, such as moving [core parsers](https://github.com/g3w-suite/g3w-client/pull/77) and [validators](https://github.com/g3w-suite/g3w-client/pull/76) under utils, adding a [src/components folder](https://github.com/g3w-suite/g3w-client/pull/83) for Vue single file components, and introducing [src/services](https://github.com/g3w-suite/g3w-client/pull/95) and [src/store](https://github.com/g3w-suite/g3w-client/pull/94) folders for the singleton refactors. Alongside them I filed issues on ideas like [migrating jQuery Deferred to native Promises](https://github.com/g3w-suite/g3w-client/issues/82), [consolidating services](https://github.com/g3w-suite/g3w-client/issues/90) and [documenting event emitters](https://github.com/g3w-suite/g3w-client/issues/92).

I also spent time on the plugin side. I opened pull requests to refactor plugin constructors in [qplotly](https://github.com/g3w-suite/g3w-client-plugin-qplotly/pull/4) and [elevation-profile](https://github.com/g3w-suite/g3w-client-plugin-elevation-profile/pull/3), opened a pull request for a [sidebar plugin example](https://github.com/g3w-suite/g3w-client-plugin-sidebar/pull/1), and proposed renaming several plugin repositories. I also proposed a [plugin development README](https://github.com/g3w-suite/g3w-client/pull/73) for the client.

Smaller contributions went elsewhere: a fix for the \`.env.example\` comment handling in [g3w-suite-docker](https://github.com/g3w-suite/g3w-suite-docker/pull/53), and a few issues on the [workshop-ol](https://github.com/gis3w/workshop-ol/issues/1) examples.
