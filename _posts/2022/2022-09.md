# Client Refactors, Repo Templates and Docker Config Sharing

*Devlog: 2022-09*

In September I contributed to the [g3w-client](https://github.com/g3w-suite/g3w-client), where I opened a series of refactoring pull requests, such as moving [vue.filter](https://github.com/g3w-suite/g3w-client/pull/179) and [vue.globalcomponents](https://github.com/g3w-suite/g3w-client/pull/178) into the app's main entry and adding a [mixins folder](https://github.com/g3w-suite/g3w-client/pull/176). I also opened an issue about [refactoring and deleting the gui folder](https://github.com/g3w-suite/g3w-client/issues/193), and I reviewed pull requests on splitting components like [Catalog.vue](https://github.com/g3w-suite/g3w-client/pull/213) and [Map.vue](https://github.com/g3w-suite/g3w-client/pull/220).

On the housekeeping side, I opened pull requests adding issue and pull request templates, such as [bug\_report.yml](https://github.com/g3w-suite/g3w-client/pull/188) for the client, plus \`.gitattributes\` files to enforce LF line endings in [g3w-admin](https://github.com/g3w-suite/g3w-admin/pull/386) and [g3w-suite-docker](https://github.com/g3w-suite/g3w-suite-docker/pull/76). In the Docker repo, I opened pull requests to [share common docker-compose configurations](https://github.com/g3w-suite/g3w-suite-docker/pull/79) and to [merge the SSL nginx config](https://github.com/g3w-suite/g3w-suite-docker/pull/77) into a single server, along with a batch of issues about Docker secrets and nginx environment variables.

I also spent some time on [Raruto/leaflet-elevation](https://github.com/Raruto/leaflet-elevation), opening a [pull request for the default button icon URL](https://github.com/Raruto/leaflet-elevation/pull/214) and reviewing two others.
