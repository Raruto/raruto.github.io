# Build Layout, Store State and Docker Dev Proposals

*Devlog: 2022-08*

In August I opened pull requests in [g3w-client](https://github.com/g3w-suite/g3w-client) proposing changes to the build and project layout: a [gulpfile refactor](https://github.com/g3w-suite/g3w-client/pull/158), [moving the assets folder into src](https://github.com/g3w-suite/g3w-client/pull/154), [removing deprecated npm scripts](https://github.com/g3w-suite/g3w-client/pull/152), and [dropping md5 hashes from index.prod.html](https://github.com/g3w-suite/g3w-client/pull/151). I also opened pull requests to [move the application state into the store](https://github.com/g3w-suite/g3w-client/pull/134) and [delete unused utility files](https://github.com/g3w-suite/g3w-client/pull/133).

On the docker side, I worked in [g3w-suite-docker](https://github.com/g3w-suite/g3w-suite-docker). I opened an [issue about using static overrides while developing](https://github.com/g3w-suite/g3w-suite-docker/issues/61) and pull requests for [template search paths](https://github.com/g3w-suite/g3w-suite-docker/pull/58) and [disabling auto-restart in the dev compose file](https://github.com/g3w-suite/g3w-suite-docker/pull/59). I also opened a [BrowserSync proxy pull request](https://github.com/g3w-suite/g3w-client/pull/150) for docker development. Smaller touches reached [g3w-admin](https://github.com/g3w-suite/g3w-admin/pull/360), the plugin skeleton, and the sidebar plugin.

Alongside that, I reviewed pull requests in g3w-client, including the [geocoding control](https://github.com/g3w-suite/g3w-client/pull/131), the [vector tile layer](https://github.com/g3w-suite/g3w-client/pull/161), and a [circular dependency fix](https://github.com/g3w-suite/g3w-client/pull/143). I also opened issues covering [release tag usage](https://github.com/g3w-suite/g3w-client/issues/112) and [version compatibility checks](https://github.com/g3w-suite/g3w-client/issues/109).
