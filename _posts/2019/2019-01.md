# Commits to wp-devops

*Devlog: 2019-01*

In January I returned to [WP DevOps](https://github.com/Raruto/wp-devops), my collection of WordPress development helpers. A [commit](https://github.com/Raruto/wp-devops/commit/eb381fee60e35aedd885d1fb9a880d7095d971b3) disabled the admin menu styling on live servers, followed by a version update.

The project's README describes a menu that can visually distinguish development and production environments. The January change is a reminder that a helpful development cue also needs to fit the environment where it appears. The [project article](https://github.com/Raruto/wp-devops) covers the rest of the toolbox.
