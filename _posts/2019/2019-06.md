# Leaflet Plugins, Packaging, and Gesture Handling

*Devlog: 2019-06*

In June I authored commits in [leaflet-kmz](https://github.com/Raruto/leaflet-kmz), [leaflet-ui](https://github.com/Raruto/leaflet-ui), [leaflet-transparency](https://github.com/Raruto/leaflet-transparency), [leaflet-control-layers-inline](https://github.com/Raruto/leaflet-control-layers-inline), [leaflet-pointable](https://github.com/Raruto/leaflet-pointable), [leaflet-trails](https://github.com/Raruto/leaflet-trails) and [raruto.github.io](https://github.com/Raruto/raruto.github.io).

![Illustration of leaflet-ui](../img/leaflet-ui.png)

*An illustration of leaflet-ui.*

Packaging and gesture handling got some attention too. I pushed commits to [leaflet-npm](https://github.com/Raruto/leaflet-npm) and [leaflet-gesture-handling](https://github.com/Raruto/leaflet-gesture-handling), and I opened a pull request, [v1.1.9](https://github.com/elmarquis/Leaflet.GestureHandling/pull/43), on the upstream Leaflet.GestureHandling project. Along the way I filed an issue on togeojson about [missing .umd files in releases after 1.0.0](https://github.com/placemark/togeojson/issues/13). I also made a few commits to [wordpress-git](https://github.com/Raruto/wordpress-git) and touched [leaflet-elevation](https://github.com/Raruto/leaflet-elevation) briefly.

TAn illustrationk especially well together: [leaflet-trails](https://github.com/Raruto/leaflet-trails) brings [Waymarked Trails](https://waymarkedtrails.org/) overlays into Leaflet, while [leaflet-pointable](https://github.com/Raruto/leaflet-pointable) makes semi-transparent tiled overlays interactive. The [trails examples](https://raruto.github.io/leaflet-trails/examples/leaflet-trails_overlays.html) combine hiking and cycling routes with a topographic base map; the separate [pointable demo](https://raruto.github.io/leaflet-pointable/examples/leaflet-pointable.html) responds to clicks on an overlay.

![Waymarked trails on a Leaflet map](../img/leaflet-trails.png)

*An illustration of the trails overlay.*

For application setup rather than map behavior, [leaflet-npm](https://github.com/Raruto/leaflet-npm) provides starter projects with separate Browserify, Rollup and webpack branches. Its README explains how to work in each source folder and build it; check the old dependency versions before reusing a template.

I also worked on [leaflet-gesture-handling](https://github.com/Raruto/leaflet-gesture-handling), based initially on [Elmarquis's project](https://github.com/elmarquis/Leaflet.GestureHandling). It helps distinguish page scrolling from intentional map zooming, as shown in the [demo](https://raruto.github.io/leaflet-gesture-handling/examples/leaflet-gesture-handling.html).

![A map prompting the user to use Ctrl and scroll](../img/leaflet-gesture-handling.png)

*The gesture-handling prompt.*

The [leaflet-control-layers-inline demo](https://raruto.github.io/leaflet-control-layers-inline/examples/leaflet-control-layers-inline.html) puts street, terrain and imagery choices into a horizontal layer selector.

![An inline layer selector on a map](../img/leaflet-control-layers-inline.png)

*The inline layers control.*

Finally, [leaflet-ui](https://github.com/Raruto/leaflet-ui) gathers base layers and map controls into a configurable Leaflet preset. Its README explains how to choose base layers and enable, disable or configure controls, and the [demo](https://raruto.github.io/leaflet-ui/examples/leaflet-ui.html) shows them working together.
