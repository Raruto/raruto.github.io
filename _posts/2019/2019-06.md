# Making a Tiled Overlay Pointable

*Projects: 2019-06*

An overlay can be more than a picture on top of a map. My [leaflet-pointable](https://github.com/Raruto/leaflet-pointable) repository, created in June, adds interaction with semi-transparent tiled overlays on Leaflet maps.

The [example](https://raruto.github.io/leaflet-pointable/examples/leaflet-pointable.html) combines a base map and a trails overlay, then responds to a click on the overlay. It's a small piece that also appears in the examples for [leaflet-trails]({{ '/blog/2019-06-07-leaflet-trails-project.html' | relative_url }}).

# Following Waymarked Trails in Leaflet

*Projects: 2019-06*

My [leaflet-trails](https://github.com/Raruto/leaflet-trails) repository dates back to June. It connects Leaflet maps with [Waymarked Trails](https://waymarkedtrails.org/), putting route overlays into a map.

The project's examples include [different overlay arrangements](https://raruto.github.io/leaflet-trails/examples/leaflet-trails_overlays.html) and an integration with Leaflet UI. The README also uses [leaflet-pointable]({{ '/blog/2019-06-07-leaflet-pointable-project.html' | relative_url }}) in its example, connecting route imagery with map interaction.

The example combines hiking and cycling overlays with a topographic base map. That separation lets the route information sit on top of the geographic context instead of replacing it.

# A Few Ways to Bundle a Leaflet Map

*Projects: 2019-06*

Rather than another map control, [leaflet-npm](https://github.com/Raruto/leaflet-npm) is my collection of starting points for bundling a Leaflet application with npm. The repository dates back to June.

The README points to separate Browserify, Rollup and webpack branches: pick a setup, work in its source folder and build the result. It's a snapshot of those toolchains, so check dependency versions before using an old template for a new project.

# Let the Page Scroll, Not Just the Map

*Projects: 2019-06*

Scrolling a page shouldn't have to mean accidentally zooming its map. My [leaflet-gesture-handling](https://github.com/Raruto/leaflet-gesture-handling) repository, created in June, adjusts Leaflet's scroll and touch interactions to help the two coexist.

It was initially based on [Elmarquis's Leaflet.GestureHandling](https://github.com/elmarquis/Leaflet.GestureHandling). The [demo](https://raruto.github.io/leaflet-gesture-handling/examples/leaflet-gesture-handling.html) shows the prompt for using a modifier key to zoom the map.

The distinction is especially noticeable when the map sits in the middle of a longer page: ordinary scrolling can keep moving the page, while an intentional gesture works with the map.

# A Layer Switcher, Laid Out Inline

*Projects: 2019-06*

My [leaflet-control-layers-inline](https://github.com/Raruto/leaflet-control-layers-inline) repository dates back to June. It gives Leaflet's layer selector an inline layout: the same job of choosing layers, presented differently.

The [demo](https://raruto.github.io/leaflet-control-layers-inline/examples/leaflet-control-layers-inline.html) puts the control on a map with several base-layer choices. Sometimes a map needs a new data source; sometimes it just needs a tidier place to choose one.

The example brings street, terrain and imagery layers into one selector, making the visual difference between those backgrounds easy to try without leaving the map.

![An inline layer selector on a map]({{ '/img/leaflet-control-layers-inline.png' | relative_url }})

*The inline layers control.*

# A Ready-to-Use Interface for Leaflet

*Projects: 2019-06*

My [leaflet-ui](https://github.com/Raruto/leaflet-ui) repository dates back to June. It gathers base layers, map controls and interface defaults into a Leaflet preset.

The current README documents options for choosing base layers and enabling or configuring individual controls. The [demo](https://raruto.github.io/leaflet-ui/examples/leaflet-ui.html) brings them together: a useful way to see how the smaller map controls fit into a larger interface.

The documented options also allow individual controls to be disabled or customized, rather than treating the preset as a fixed interface. The image below is a current illustration of that collection.
