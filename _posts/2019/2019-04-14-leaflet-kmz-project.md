# Putting KML and KMZ on the Map

*Projects: 2019-04*

A map can display more than the tiles it starts with. My [leaflet-kmz](https://github.com/Raruto/leaflet-kmz) repository, created in April, brings KML and KMZ data into Leaflet.

The current README documents native browser decompression for supported KMZ archives and lists the archive formats it can handle. The project credits [A-Lurker](https://github.com/a-lurker/leaflet-kmz) and [BrandonXiang](https://github.com/brandonxiang/leaflet-geojson-vt), among its contributors. There are examples for [KMZ layers](https://raruto.github.io/leaflet-kmz/examples/leaflet-kmz.html) and [vector grids](https://raruto.github.io/leaflet-kmz/examples/leaflet-kmz_gridlayer.html).
