# A Renaissance Board Game in Java

*Projects: 2017-05*

Looking back to the 2016–2017 academic year, [IlMagnifico](https://github.com/Raruto/IlMagnifico) was a Java adaptation of the board game *Lorenzo il Magnifico*, developed for a Software Engineering course at Politecnico di Milano. The repository dates from May.

The [user guide](https://github.com/Raruto/IlMagnifico) describes both command-line and graphical interfaces, with a client connecting to a server through either sockets or RMI. A board game became an opportunity to work with turns, interfaces and networked players—not just pieces on a table.
