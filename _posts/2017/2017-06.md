# More Work on IlMagnifico

*Devlog: 2017-06*

In June I returned to [IlMagnifico](https://github.com/Raruto/IlMagnifico), the Java board-game adaptation from my Software Engineering course. One small [repository change](https://github.com/Raruto/IlMagnifico/commit/9e2c6d34621bac09dd3f60e2ac0eb2f800dd2da8) removed an incorrect ignore rule for Java files.

Not every useful change comes with a new feature: keeping source files visible to version control matters too. For the larger picture, the [project retrospective]({{ '/blog/2017-05-09-ilmagnifico-project.html' | relative_url }}) covers the client/server setup and the command-line and graphical interfaces described in the user guide.
