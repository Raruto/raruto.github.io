# A Renaissance board game in Java

*Devlog: 2017-05*

In May I was working on [IlMagnifico](https://github.com/Raruto/IlMagnifico), a Java adaptation of *Lorenzo il Magnifico*, board game developed for the Software Engineering course at Politecnico di Milano (2016–2017 academic year). The work involved more than the board itself: players needed a way to connect and take turns, through either sockets or RMI.

The repo includes a [game schema](https://github.com/Raruto/IlMagnifico/commit/6bcb1be0c3283ad32c47c31077aff04e88661f6e), experiments with [JavaFX](https://github.com/Raruto/IlMagnifico/commit/833ac4a3907e445fe481faf545751fa553a3204c).

I wrote more about interfaces and networked players in the [IlMagnifico retrospective](https://github.com/Raruto/IlMagnifico).
