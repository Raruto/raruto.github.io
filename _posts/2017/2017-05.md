# Commits to IlMagnifico

*Devlog: 2017-05*

In May I was working on [IlMagnifico](https://github.com/Raruto/IlMagnifico), a Java adaptation of a board game developed for the Software Engineering course at Politecnico di Milano. The work involved more than the board itself: players needed a way to connect and take turns.

The history includes a [game schema](https://github.com/Raruto/IlMagnifico/commit/6bcb1be0c3283ad32c47c31077aff04e88661f6e), experiments with [JavaFX](https://github.com/Raruto/IlMagnifico/commit/833ac4a3907e445fe481faf545751fa553a3204c), and the start of a [client/server project using RMI and sockets](https://github.com/Raruto/IlMagnifico/commit/8683aab07ad331c152baafb14b282639bf6cb984). I wrote more about the project and its interfaces in the [IlMagnifico retrospective]({{ '/blog/2017-05-09-ilmagnifico-project.html' | relative_url }}).
