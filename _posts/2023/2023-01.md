# Sentry, Yeoman and Leaflet 1.9.3 Proposals

*Devlog: 2023-01*

In January I contributed to g3w-suite projects. In [g3w-client](https://github.com/g3w-suite/g3w-client) I opened pull requests to [remove the yeoman dependency](https://github.com/g3w-suite/g3w-client/pull/314), [add a Sentry monitor plugin integration](https://github.com/g3w-suite/g3w-client/pull/313), and [localize error page messages](https://github.com/g3w-suite/g3w-client/pull/310). I also opened an [issue about making the repository an installable Python package](https://github.com/g3w-suite/g3w-client/issues/292) and reviewed a number of other pull requests there, including the [jQuery-to-native-Promise migration](https://github.com/g3w-suite/g3w-client/pull/308).

Around the same time I worked on the Sentry side in [g3w-admin-sentry-monitor](https://github.com/g3w-suite/g3w-admin-sentry-monitor) and opened a [pull request in g3w-admin](https://github.com/g3w-suite/g3w-admin/pull/446) to remove the native Sentry integration. Earlier in the month I opened a [Makefile pull request for g3w-admin](https://github.com/g3w-suite/g3w-admin/pull/436) and committed to [makefiles](https://github.com/g3w-suite/makefiles).

Outside g3w, I opened a [pull request adding Leaflet 1.9.3 support](https://github.com/Raruto/leaflet-rotate/pull/21) in leaflet-rotate, reviewed [another fix there](https://github.com/Raruto/leaflet-rotate/pull/20), and authored commits in that repository and in [leaflet-ui](https://github.com/Raruto/leaflet-ui).
