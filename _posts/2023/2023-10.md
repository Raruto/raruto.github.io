# Editing API Changes and a Bing Geocoding Proposal

*Devlog: 2023-10*

In October I contributed to [g3w-client](https://github.com/g3w-suite/g3w-client). I opened a pull request to [move the utils folder](https://github.com/g3w-suite/g3w-client/pull/508) and another to [remove the editing API](https://github.com/g3w-suite/g3w-client/pull/493) tied to the editing plugin. On the plugin side, I opened pull requests to [show value relation values](https://github.com/g3w-suite/g3w-client-plugin-editing/pull/64) in layer relations and to [include files from core](https://github.com/g3w-suite/g3w-client-plugin-editing/pull/65). I also authored commits in g3w-client, [g3w-client-plugin-editing](https://github.com/g3w-suite/g3w-client-plugin-editing) and [g3w-suite-demo-projects](https://github.com/g3w-suite/g3w-suite-demo-projects).

I also opened a [pull request for a Bing geocoding provider](https://github.com/g3w-suite/g3w-client/pull/505), after first opening an [issue for the Bing geocoding control](https://github.com/g3w-suite/g3w-client/issues/498) and a [follow-up issue](https://github.com/g3w-suite/g3w-client-plugin-editing/issues/68) about saving geocoding results into an editable point layer. In g3w-admin, I opened issues about an [optional group name](https://github.com/g3w-suite/g3w-admin/issues/612) and a [default start extent](https://github.com/g3w-suite/g3w-admin/issues/611).

I reviewed several pull requests as well, including [layer field selection for downloads](https://github.com/g3w-suite/g3w-client/pull/506), [value relation fixes](https://github.com/g3w-suite/g3w-client/pull/504), [editable vector joins](https://github.com/g3w-suite/g3w-client/pull/483) and [stored expression filters](https://github.com/g3w-suite/g3w-client/pull/503). Outside that project, I opened a pull request in togeojson for a [GPX metadata type](https://github.com/placemark/togeojson/pull/123).
