# Fake Plotly and iframe refactor


*Devlog: 2023-12*

In December I contributed to the [g3w-admin-ps-timeseries](https://github.com/g3w-suite/g3w-admin-ps-timeseries) plugin. I started with a pull request on [fake Plotly data](https://github.com/g3w-suite/g3w-admin-ps-timeseries/pull/1), kept committing to the repository over the following days, and later opened a [Replicas](https://github.com/g3w-suite/g3w-admin-ps-timeseries/pull/2) pull request. I also made commits to the [editing plugin](https://github.com/g3w-suite/g3w-client-plugin-editing) and to the [backlog](https://github.com/g3w-suite/backlog) repository, where I opened a couple of issues.

On the client side, I opened an [Iframe refactor](https://github.com/g3w-suite/g3w-client/pull/529) pull request and another one to [deprecate some class attributes](https://github.com/g3w-suite/g3w-client/pull/533). I also reviewed several pull requests across the suite, including [external WMS query fixes](https://github.com/g3w-suite/g3w-client/pull/536), [deep relations in editing](https://github.com/g3w-suite/g3w-client-plugin-editing/pull/80), and [cache invalidation in g3w-admin](https://github.com/g3w-suite/g3w-admin/pull/689).
