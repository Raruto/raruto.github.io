# One editing button, tighter checks

*Devlog: 2023-09*

In September I authored commits in the [editing plugin](https://github.com/g3w-suite/g3w-client-plugin-editing). Near the end of the month I opened an [issue proposing a single editing button](https://github.com/g3w-suite/g3w-client-plugin-editing/issues/60) in the left sidebar to replace the separate editing tools. I also committed to [g3w-client](https://github.com/g3w-suite/g3w-client), [g3w-suite-demo-projects](https://github.com/g3w-suite/g3w-suite-demo-projects) and [g3w-suite-docker](https://github.com/g3w-suite/g3w-suite-docker).

On the client side, I opened a pull request to [delete the old error parser](https://github.com/g3w-suite/g3w-client/pull/489), another for a [stricter undefined check in QGISProvider](https://github.com/g3w-suite/g3w-client/pull/482), and an [issue about the rightmost map controls getting cropped](https://github.com/g3w-suite/g3w-client/issues/488) when the Attribute Table is open. In docker, I opened a [pull request swapping a GitHub issue template file for config.yml](https://github.com/g3w-suite/g3w-suite-docker/pull/107).

I also reviewed several pull requests, including [editable vector joins (1:1 relations)](https://github.com/g3w-suite/g3w-client/pull/483), [multi-field relations](https://github.com/g3w-suite/g3w-client-plugin-editing/pull/53) and [snapping after stopping and starting editing](https://github.com/g3w-suite/g3w-client-plugin-editing/pull/55).
