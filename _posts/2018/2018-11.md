# Tile Proxy, Leaflet Pegman, and Site Commits

*Devlog: 2018-11*

November brought several pieces of my mapping work together: commits to the [site](https://github.com/Raruto/raruto.github.io), [tile-proxy-php](https://github.com/Raruto/tile-proxy-php) and [leaflet-pegman](https://github.com/Raruto/leaflet-pegman), among others.

On Pegman, one [change prevented panorama events from bubbling up to the Leaflet map](https://github.com/Raruto/leaflet-pegman/commit/f575b71141e1b726aad1c2875eae06b318cf838e); another adjusted the control's appearance when positioned on the left. The projects have different jobs: [Pegman]({{ '/blog/2018-11-19-leaflet-pegman-project.html' | relative_url }}) connects the map to Street View, while the [tile proxy]({{ '/blog/2018-11-25-tile-proxy-project.html' | relative_url }}) sits between a map and its tile servers.

# The Ups and Downs of a Track

*Projects: 2018-11*

A line on a map doesn't tell the whole story of a route. My [leaflet-elevation](https://github.com/Raruto/leaflet-elevation) repository, created in November, puts its elevation profile alongside the map to show the climbs and descents too.

Today's examples cover formats such as GPX, GeoJSON and KML, as well as multiple tracks and additional charts. The project was initially based on [Felix Bache's Leaflet.Elevation](https://github.com/MrMufflon/Leaflet.Elevation); the README also credits other contributors. Explore the [track demo](https://raruto.github.io/leaflet-elevation/examples/leaflet-elevation_hoverable-tracks.html) to see the map and profile together.

# Finding My Place on a Google Map

*Projects: 2018-11*

Where am I on this map? My [google-geolocate](https://github.com/Raruto/google-geolocate) repository, created in November, adds a control for finding the user's position instead of navigating there manually.

The [example](https://raruto.github.io/examples/google-geolocate/google-geolocate.html) shows the control in context. The project documentation notes that geolocation requires a secure site and that Google Maps needs an API key; browser permission is also part of the experience.

![The geolocation control on a map]({{ '/img/google-geolocate-control.jpg' | relative_url }})

# A Little Street View Companion for Leaflet

*Projects: 2018-11*

My [leaflet-pegman](https://github.com/Raruto/leaflet-pegman) repository dates back to November. It connects a Leaflet map with the Google Street View service, adding a way to move from the map to a street-level panorama.

The project credits [Daniel Pegues's earlier work](http://jsfiddle.net/pegues/a5mn1ogu/). Its current examples include [lazy loading](https://raruto.github.io/leaflet-pegman/examples/leaflet-pegman-lazyLoading.html) and a [separate panorama container](https://raruto.github.io/leaflet-pegman/examples/leaflet-pegman-panoDiv.html); using Google services still means checking their current API and key requirements.

# A Slider Between Two Maps

*Projects: 2018-11*

My [google-transparency](https://github.com/Raruto/google-transparency) repository dates back to November. It adds an opacity control to Google Maps, making it possible to adjust how much of a layer shows through.

The project credits earlier work by [Gavin Harriss](https://github.com/gavinharriss/google-maps-v3-opacity-control). Its [example](https://raruto.github.io/examples/google-transparency/google-transparency.html) shows the slider with map imagery. I later carried the idea into [leaflet-transparency]({{ '/blog/2019-05-22-leaflet-transparency-project.html' | relative_url }}).

Instead of switching an overlay entirely on or off, a slider lets the base map remain visible underneath it. That makes the relationship between the two layers easier to explore.

# A Cache Between the Map and the Tile Server

*Projects: 2018-11*

Between a map and its tile servers, there's room for a cache. My [tile-proxy-php](https://github.com/Raruto/tile-proxy-php) repository, created in November, provides a PHP caching proxy for map tiles.

The README credits [Lizard's ProxySimplePHP](https://wiki.openstreetmap.org/wiki/ProxySimplePHP) as the starting point and describes an Apache/PHP setup. It's an old project: before deploying anything similar today, check your server configuration and the tile provider's current caching and usage policies.
