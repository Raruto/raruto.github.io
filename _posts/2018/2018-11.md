# Tile Proxy, Leaflet Pegman, and Site Commits

*Devlog: 2018-11*

November brought several pieces of my mapping work together: commits to the [site](https://github.com/Raruto/raruto.github.io), [tile-proxy-php](https://github.com/Raruto/tile-proxy-php) and [leaflet-pegman](https://github.com/Raruto/leaflet-pegman), among others.

On Pegman, one [change prevented panorama events from bubbling up to the Leaflet map](https://github.com/Raruto/leaflet-pegman/commit/f575b71141e1b726aad1c2875eae06b318cf838e); another adjusted the control's appearance when positioned on the left.

For a closer look at a route's climbs and descents, [leaflet-elevation]({{ '/blog/2018-11-02-leaflet-elevation-project.html' | relative_url }}) pairs a track with its elevation profile. The current examples cover GPX, GeoJSON and KML, multiple tracks and extra charts. The project began with [Felix Bache's Leaflet.Elevation](https://github.com/MrMufflon/Leaflet.Elevation); a [track demo](https://raruto.github.io/leaflet-elevation/examples/leaflet-elevation_hoverable-tracks.html) shows the map and profile together.

![An elevation profile alongside a map]({{ '/img/leaflet-elevation.png' | relative_url }})

*A current illustration of leaflet-elevation.*

Another small map control, [google-geolocate](https://github.com/Raruto/google-geolocate), locates the user on a Google map. Its [example](https://raruto.github.io/examples/google-geolocate/google-geolocate.html) shows it in context; using it requires a secure site, a Google Maps API key and the user's browser permission.

!An illustrationol on a map]({{ '/img/google-geolocate-control.jpg' | relative_url }})

The [leaflet-pegman]({{ '/blog/2018-11-19-leaflet-pegman-project.html' | relative_url }}) control opens a Google Street View panorama from a Leaflet map. It builds on [Daniel Pegues's earlier work](http://jsfiddle.net/pegues/a5mn1ogu/); current examples cover [lazy loading](https://raruto.github.io/leaflet-pegman/examples/leaflet-pegman-lazyLoading.html) and a [separate panorama container](https://raruto.github.io/leaflet-pegman/examples/leaflet-pegman-panoDiv.html). Google API and key requirements may change.

For comparing map layers without switching an overlay completely on or off, [google-transparency](https://github.com/Raruto/google-transparency) adds an opacity slider to Google Maps. The project credits [Gavin Harriss](https://github.com/gavinharriss/google-maps-v3-opacity-control); its [example](https://raruto.github.io/examples/google-transparency/google-transparency.html) shows the control, which I later adapted for [Leaflet]({{ '/blog/2019-05-22-leaflet-transparency-project.html' | relative_url }}).

The [tile-proxy project]({{ '/blog/2018-11-25-tile-proxy-project.html' | relative_url }}) is a PHP caching proxy for map tiles, based on [Lizard's ProxySimplePHP](https://wiki.openstreetmap.org/wiki/ProxySimplePHP) and documented for an Apache/PHP setup. It's an old project, so check current server configuration and tile-provider policies before deploying anything similar.
