# A basemap for waymarkedtrails.org

*Devlog: 2018-06*

On June 27, 2018, I opened a feature request on the [waymarked-trails-site](https://github.com/waymarkedtrails/waymarked-trails-site) repository. The idea: a URL parameter for choosing the basemap type, so a map link could specify which base layer it should show.

The [feature request](https://github.com/waymarkedtrails/waymarked-trails-site/issues/299) explains the sharing problem: the site stored map settings locally, but a link to a particular map view could be more useful if it also carried the selected basemap. In particular, I wanted to be able to share the OpenTopoMap view with someone unfamiliar with the site's controls.

It's a small distinction between a map on my screen and a map someone else opens from my link.
