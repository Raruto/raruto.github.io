The illustration shows the plugin as it appears today, not necessarily its October version.

One of the site's October additions was a small [Leaflet](https://leafletjs.com/) playground, first committed on October 25. It uses [OpenTopoMap](https://opentopomap.org/) tiles; clicking adds a marker, and dragging it updates the coordinates shown in its popup.

Multiple markers can stay on the map at once, making this a simple interactive sketch from 2018, preserved as part of the site's history.

<link rel="stylesheet" href="https://unpkg.com/leaflet@1.3.1/dist/leaflet.css" crossorigin="">
<script src="https://unpkg.com/leaflet@1.3.1/dist/leaflet.js" crossorigin=""></script>
<style>
  #map img { margin: 0; padding: 0; border: 0; box-shadow: none; max-width: none; }

<div id="map" aria-label="Interactive maps playground" style="width: 100%; height: 400px;"></div>
<script>
  const map = L.map('map').setView([42.24478, 11.18408], 5);
  L.tileLayer('https://{s}.tile.opentopomap.org/{z}/{x}/{y}.png', {
    maxZoom: 17,
    attribution: 'Map data: &copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a>, <a href="http://viewfinderpanoramas.org">SRTM</a> | Map style: &copy; <a href="https://opentopomap.org">OpenTopoMap</a> (<a href="https://creativecommons.org/licenses/by-sa/3.0/">CC-BY-SA</a>)'
  }).addTo(map);
  map.on('click', function (event) {
    const marker = L.marker(event.latlng, {
      draggable: true,
      title: 'Resource location',
      alt: 'Resource Location',
      riseOnHover: true
    }).addTo(map).bindPopup(event.latlng.toString()).openPopup();
    marker.on('dragend', function (event) {
      this.bindPopup(event.target.getLatLng().toString()).openPopup();
    });
  });
</script>

The other mapping experiment was [leaflet-google](https://github.com/Raruto/leaflet-google), whose example places Google map types alongside a Leaflet base layer. The project credits earlier work by [James “Crofty” Croft](http://matchingnotes.com/using-google-map-tiles-with-leaflet); its [demo](https://raruto.github.io/examples/leaflet-google/leaflet-google.html) shows the integration. Check Google's current API requirements before using it.
