# Webhook timeouts in GitHub Updater

*Devlog: 2018-03*

At the end of March, I opened a [GitLab webhook timeout report](https://github.com/afragen/github-updater/issues/663) on GitHub Updater. The REST calls I had tried worked, but a push-triggered webhook reported a `Net::ReadTimeout`.

The report compares that result with a test endpoint that responded successfully and asks whether WordPress response time could be involved. It is an investigation, not proof of a particular cause. I later explored logging around the same problem; there's more on that in the [Git Updater retrospective]({{ '/blog/2018-05-12-git-updater-contributions.html' | relative_url }}).
