# Bringing Google Maps into Leaflet

*Projects: 2018-10*

What happens when a Leaflet map meets Google Maps? My [leaflet-google](https://github.com/Raruto/leaflet-google) repository, created in October, explores that connection. Its example shows Google map types alongside another Leaflet base layer.

The project credits the earlier work of [James “Crofty” Croft](http://matchingnotes.com/using-google-map-tiles-with-leaflet). Its [demo](https://raruto.github.io/examples/leaflet-google/leaflet-google.html) and README are a starting point for exploring the integration; check Google's current API requirements before using it.
